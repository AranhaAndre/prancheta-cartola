Prancheta Cartola 2026

Atualizar escalações e preços

O status “Provável” e os preços saem do mercado oficial do Cartola. Este painel não consegue ler a API da Globo direto (o navegador bloqueia), então traga o arquivo em 3 passos:

  1. Com o mercado aberto, abra api.cartola.globo.com/atletas/mercado.
  2. Salve a página (Ctrl+S) como mercado.json, ou selecione tudo e copie.
  3. Carregue o arquivo abaixo ou cole o conteúdo. Opcional: faça o mesmo com /partidas para saber quais jogos valem na rodada.

Também aceita o model_data.json gerado pelo script de atualização do modelo.
